# horchd <small>0.1.0</small>

> Native multi-wakeword detection daemon for Linux.

- Loads any number of openWakeWord `.onnx` models in parallel
- Broadcasts detections via D-Bus on the session bus
- Tiny, fast, runs as a systemd user unit
- One-command install · zero-cloud · built in Rust 2024
